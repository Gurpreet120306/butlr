
# BUTL-R

**Personal AI Assistant**

BUTL-R is a modular, secure, local-first personal AI assistant.

## Project goals

- Natural language interaction
- Voice-based communication
- Persistent user-approved memory
- Productivity and automation tools
- Secure computer and device integrations
- Optional local and cloud AI providers

## Technology

- Python
- PySide6 (planned desktop interface)
- SQLite (planned local database)
- Ollama (planned local AI runtime)

## Development status

Initial project foundation completed.

## Running the application

Activate the virtual environment and run:

```bash
python app/main.py
```

## Security principles

- Local-first by default
- Permission-based actions
- Explicit confirmation for sensitive operations
- No unrestricted system command execution
